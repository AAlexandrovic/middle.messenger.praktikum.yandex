
## Описание

Чат для общения между пользователями

## Установка
После клонирования репозитория: 

- `npm install` — установка пакетов,
- `npm run build` — сборка проекта,
- `npm run preview` — просмотр собранного проекта,
- `npm run dev` — запуск проекта в режиме разработчика.
- `npm run start` — запуск и сборка проекта в режиме preview.
